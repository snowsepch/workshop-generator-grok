## 使用方式

1. 直接用瀏覽器開啟資料夾內的 `index.html`。
2. **一句話智能推薦**：輸入顧客需求（例如「我想看 iPhone Duo 摺疊機怎麼雙螢幕多工」或「iPhone 18 Pro 可變光圈拍照」），即刻自動勾選最匹配主題並給予門市解說理由。
3. **快速預設標籤**：可直接點擊頂部快捷晶片（iPhone Duo、iPhone 18 Pro、iPhone 17e、iPad mini、MacBook Neo、Watch 12、iOS 27 等）。
4. **生成交付產出**：
   - 互動簡報預覽與全螢幕投影展示
   - 宣傳海報產生（含單堂課與雙堂課版面，奶油底清爽通透風）
   - 社群全通路文案（Threads、IG、LINE、FB）
   - 備課講稿下載（.txt）
   - PPTX 簡報檔匯出（可直接於 Keynote / PowerPoint 開啟編輯）
   - 進入即時編輯模式修改簡報細節
