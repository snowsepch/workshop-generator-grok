# Apple Shop 小教室專案 · Grok 版

這是使用 Grok（xAI）協助開發與持續優化的版本，為單一 HTML 檔案，開啟瀏覽器即可直接使用，無需安裝任何額外程式。

## 與原本版本的主要差異

- **台灣用語全面修正**  
  依照 Apple 台灣官網用語重新校正所有內容：
  - Journal → 「日誌與回憶」（不再出現英文前綴）
  - Freeform → 「無邊記」
  - 其他產品名稱、介面用語、說明文字均已同步修正

- **動手實作時間大幅優化**  
  原本「動手試 15 分鐘」調整為**25–30 分鐘**，並依照以下規則智慧調整：
  - 依實際任務數量動態決定要做幾個練習（2–5 個）
  - 按照任務內容比例分配時間（講師示範 + 學員操作 + 分享討論）
  - 所有簡報頁面、講師引導範例、時間提示、PPTX 輸出均會同步更新實際分鐘數

- **融合模式標題改為情境式單一主題**  
  選取多個主題後，不再產生「主題A × 主題B」或「等 N 個主題」的堆疊標題，而是依生活情境產生自然的主題名稱，例如：
  - 「家庭數位生活體驗」
  - 「Mac 日常操作體驗」
  - 「旅行智慧生活體驗」
  包含簡報封面、議程、海報、社群文案、PPTX 全部使用同一智慧標題邏輯。

- **修復重新生成狀態問題**  
  解決「先執行一次融合模式後，更改左側課綱，再按『生成簡報』，系統會停留在上一個版本的主題」的問題。現在每次生成都會正確讀取當前左側即時勾選的主題。

- **Mac 操作主題拆分與日常化改寫**  
  將原本單一 Mac 主題拆成兩個獨立課綱：
  - 「Mac 簡易操作」：觸控板手勢、Spotlight、Dock、基本檔案管理
  - 「Mac 進階實用」：Handoff、Universal Control、iCloud 共享、Time Machine、Shortcuts 自動化
  所有說明與場景均改寫為「銀髮族第一次用 Mac 寫信給孫子」「家長整理全家照片給長輩」「上班族跨裝置接力工作」等真實日常生活情境。

- **新增適合課堂教學的 App（移除不適合項目）**  
  新增以下適合上課實際操作、免費或免費核心的 App：
  - Apple 官方：照片、訊息、FaceTime、地圖、健康、即時翻譯
  - 其他優質工具：YouTube、Canva、CapCut、Notion、Spotify
  已移除電商經營（蝦皮）、外送（Uber Eats）、IG 等不適合課堂教學分享的主題。

- **年齡層語言與場景調整**  
  - 青少年：使用「你」，強調創作、分享、找到自己風格
  - 銀髮族：使用「您」，步調放慢、強調與兒孫聯繫、健康日誌等
  各年齡層的 agendaNote、handsNote、closeNote 均已針對實際生活情境重新撰寫。

- **雙堂課海報功能強化**  
  可一次產生「本期＋下期」兩堂課的海報。即使其中一堂是融合多主題，也會正確顯示各自的智慧標題，並在海報上標註涵蓋哪些子主題。

- **其他實用性優化**  
  - 智能推薦後手動取消項目，產生的簡報內容會正確跟著更新
  - 所有輸出（簡報預覽、海報、社群文案、備課講稿、.pptx）均即時依左側選擇產生
  - 講師講稿、PPTX 內容更貼近實際上課可操作的步驟

## 使用方式

1. 直接用瀏覽器開啟本資料夾內的 `index.html`
2. 左側勾選想要的主題（可單一或多主題融合）
3. 右側選擇年齡層
4. 填寫日期、時長、人數後，按「生成簡報」
5. 生成後可繼續操作：
   - 產生宣傳海報（含雙堂課版本）
   - 產生社群文案
   - 下載備課講稿（.txt）
   - 下載 .pptx（可直接用 Keynote 開啟編輯）
   - 進入編輯模式直接修改簡報文字
